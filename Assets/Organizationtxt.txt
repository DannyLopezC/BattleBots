Model = state and rules
View = Unity events and representation
Controller = coordination

Project vision:
1. Build mode: where you build the robot
2. Battle mode: test movement, weapons, damage and combat
3. Shared robot domain: everything that defines a robot, parts, and how stats are calculated

Phase 1:
Checklist:
- basic chasis
- defined sockets
- two functional wheels
- a simple weapon part
- an assemblable robot
- recalculate basic stats

Goal: project structure, robot domain, basic buld flow, MVC conexion, a simple modular robot existing

Phase 2:
Checklist:
- select part from UI
- visual preview
- validate if part can be placed
- place/remove parts
- recalculate stats
- update stats panel

Goal: to be able to build without touching code for each part

Phase 3:
Checklist:
- basic wheeled locomotion
- turn
- player input
- reasonable center of mass
- minimum stability

Goal: to move the built robot

Phase 4:
Checklist:
- simple spinner
- activation/deactivation
- visible collision
- basic visual feedback

Goal: robot doing something "battlebots"

Phase 5:
Checklist:
- very simple dummy enemy or bot
- localized damage per piece
- a piece can break or come loose
- damage feedback

Goal: first real combat

Phase 6:
Checklist:
- spawn player vs enemy
- restart
- simple win condition
- minimum HUD


* is for later implementations if needed
| is scripts that are already on the project
